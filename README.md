AM Dashboard is a free web app for people who plays to <a href="https://www.airlines-manager.com/">Airlines Manager : Plane Tycoon®</a>. Thanks to it, they may :
- analyze their company stats with a full dashboard composed by many charts
- manage their hubs and routes
- assign their aircrafts and follow their flights in real time

## Connection & Users

- Authenticate with default admin user
- Create your own admin user and authenticate with it
- Delete default admin user

## Airline customizing

With the help of a form, you can :
- define your ICAO code
- rename your airline
- customize your logo
